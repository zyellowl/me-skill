# me-skill

从具体行为中抽象归纳反复模式，帮助任何使用者更了解自己的 AI skill。

从一件具体的事聊起，比较不同事件和反例，再共同核对可能的模式与解释。借用弗洛伊德的本我/自我/超我、防御机制、自由联想和重复强迫作为可被事实与用户纠正的假设，不由 AI 替人下结论。自我理解本身就是目的，不强制转为行为改变。

仅凭对话即可使用；me-cli 风格的个人记录是可选来源，读取或保存需有用户授权。

- `SKILL.md`：给 AI 的方法与规则
- `references/`：证据规则、按需使用的情境方法与完全虚构的示例
- `reflect.py`：从个人记录库提取素材（`ME_HOME=/path/to/data python3 reflect.py --days 30`）

不是心理治疗，不做诊断。本仓库只保存通用方法与完全虚构的示例，不收录真实个人资料、原话或经历；个人数据仅保存在获授权的本地或私有记录中。
