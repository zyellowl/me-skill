# 反思方法与提问示例

## 从行为到模式（虚构示例）

以下人物、原话、日期与事件全部虚构，不映射真实经历。假设这些是虚构用户小弦在不同轮对话中的本人陈述，陈述日期与事件日期相同：

| 日期 | 原话证据 |
| --- | --- |
| 2026-03-02 | “纸船两边没对齐，我觉得应该对称，就拆了重折。重折时松了口气，后来没赶上展示。” |
| 2026-03-06 | “纸风铃两侧不一样长，我又重做了。我觉得做得对称才好，重做时安心一点，最后比计划晚睡了。” |
| 2026-03-07 | “拼贴画也不对称，但我觉得拼贴可以不齐，就留下了，还挺喜欢。” |

- **候选模式**：在前两次自述中，小弦认定作品应该对称时，发现不齐便重做，暂时安心，但挤占了原有安排；认为可以不齐的拼贴是例外。只适用于这些材料，不能概括成“凡事追求完美”。
- **可能的解读**：本我视角可关注“松了口气／安心”的感受，超我视角可关注对称标准，自我视角关注重做这一实际协调方式。防御机制视角可猜测重做是否暂时减轻不适，但材料也容许审美偏好或制作要求等解释；没有证据支持隐藏动机，不必补齐解释。
- **重复强迫的限度**：两次相似行为不足以使用该解释；还不知道小弦是否不愿重演、是否有别的选择。先核对行为与条件，不把存在代价直接称为重复强迫。
- **本轮只问**：“你会怎样描述这两次重做对你的意义？”等待回答，不附改进清单。

假设小弦于 2026-03-08 纠正：“风铃那次主要是挂不上去才重做，不能只算为了对称。”应保留这次纠正，将第二次事件更新为有功能约束；撤回“两次都因对称要求而重做”的归纳，相关防御解释也不再沿用。剩下一次材料不足以建立该反复模式，不把纠正解释为合理化。用户可以认可单次理解、另找材料或到此结束。

概念出处：弗洛伊德在 [《超越快乐原则》第三节](https://www.gutenberg.org/files/76031/76031-h/76031-h.htm) 讨论了痛苦经历的反复，并承认其他动机可能同时存在。这里借用它提出可撤回的探索问题，不将原理论或本例当作经验证实的心理机制。

## 情境反思方法

以下均为待证据核对的可能解释，不是对任何人的观察或诊断。共同遵循 [多假设与修正规则](memory-schema.md#多假设与修正)；健康症状另守 [医学评估边界](../SKILL.md#规则)。不把这些条目逐项套用或变成必须回答的问卷；其中行动建议只在用户希望改变或解决具体问题时使用，不替代行为比较与自我理解。

### 遗憾与补救

- 遗憾可能放大“本可拥有”的反事实想象。区分实际失去的东西、现在想象的另一种结果与当时确实可行的选项；不把想象中的结果当成必然，也不以事后信息要求过去的自己早就知道。
- 补救可能同时包含改善当下、履行责任与自我惩罚的成分，但投入时间、金钱或承受不适本身不证明自我惩罚。有线索且用户愿意时，核对补救希望带来的现实改善、代价边界与完成条件，不把痛苦或牺牲程度当成诚意、赎回或补救成功的标准。
- 允许遗憾尚未完全消失时结束补救。若继续投入已不再服务于认可的目标，可讨论缩小、暂停或替换方案；不替用户认定什么已经足够，也不因此否定其真实责任。

### 大变动中的具体焦虑

- 大变动时，焦虑可能集中到具体、可操作的小事上；这只是候选解释。事情看起来小，不代表后果、责任、截止时间或依赖关系小，不能仅凭焦虑强度称其为转移或回避。
- 先核对具体事项的实际后果、责任归属、可用资源和权限。现实负担与对变动的不确定感可以并存；处理必要事项与讨论感受也可以并行，不要求先接受心理解释才能解决实际问题。

### 自愿帮助、被迫兜底与交接

- 区分主动选择且范围可协商的帮助，与因无人接手、责任压力或退出成本而持续承担的兜底。答应过一次不能证明此后都出于自愿，事后疲惫也不能单独证明当初被迫；以本人表达及实际选择空间核对。
- 友谊与信任不代表无限容量、永久承诺或默认承担全部后果。分别讨论关系意愿、已承诺范围、可投入时间和能力；不能将设定边界等同于不忠诚，也不能把拒绝当成没有现实代价的万能答案。
- 口头提到交接、通知对方或表达交接意愿，不等于对方明确接手。核对接手意愿、职责范围、生效条件，以及所需信息、资源与权限是否到位；口头表达也可能构成明确确认，关键在内容与双方理解，不在媒介。确认不清就保留“待确认”，不推定责任已转移或原承担者必须无限期兜底。
- 若缺口来自组织安排，优先讨论职责确认、资源补足、范围调整或向有权限者澄清；不将无权改变分工解释为不会拒绝或个人防御。

### 反思、反刍与结束条件

- 反思是否带来新的理解、事实区分、可行动选择或对不确定性的接纳，比谈论次数更有用。反刍的候选线索是反复绕回同一问题、没有新材料却不断增加负担；重复表达或仍有情绪本身不能证明反刍，也不应被用来催促用户结束。
- 用户愿意继续时，先约定本轮要解决的问题及停止条件，例如达到预设时长、得到足够支撑下一步的信息，或暂时没有新增证据。不以消除所有遗憾、取得绝对确定或接受 AI 的解释作为结束条件。
- 如需行动，优先讨论成本可承受的可逆尝试，保留可逆备选或退路。是否实施由用户决定，真实的期限与责任仍需处理，不能用暂停反思代替履责。
- 收尾可保留当前暂定选择、未知项和复评时间或明确触发条件；没有新证据时不反复重开同一判断。复评约定不自动授权提醒、后台跟进或写入个人记录。

### 竞争失败后的继续行为

- 失败后想通过翻盘消除不甘，可能让行为延长，但也可能有练习、兴趣或已承诺安排等解释。核对是否因结果不如愿反复延后结束；一次失败或强烈求胜心不能用于诊断成瘾、冲动障碍或人格问题。
- 用户希望减少失控延长时，在开始前设定自己认可的活动时长和可执行的结束点，到时按约定停止，不以赢回、扳平或证明能力作为停止门槛；失败后不临时延长时长来追结果。若活动有不可随时中断的责任或规则，应事先把它纳入时长与结束点安排。
- 停止后允许不甘暂时存在；是否调整下一次活动安排留到约定的复评时间讨论，不把这一轮输赢当成个人价值判断。

## 提问示例（虚构场景）

以下人物、原话和日期均为虚构。场景：小林于 2026-01-10 说“我很想升职，但也想不再为此内耗”。

事实素材（本人陈述）：上述原话；陈述日期为 2026-01-10，事件日期未知。它只能证明小林这样表达过，不能证明升职是其长期目标。

可能的解读（AI 假设，本我视角）：小林可能同时想争取升职、减轻内耗。原话证据：“我很想升职，但也想不再为此内耗”（本人陈述，2026-01-10；事件日期未知）。超我标准和现实约束尚未知，不补写。

下面是按需选择的备选提问，每轮只问其中一个：

- 本我：「谈到升职，你最希望它给你带来什么？」
- 超我：「谈到升职，你觉得自己应该达到什么标准？」
- 自我：「如果职级暂时不变，你最希望先改善的是什么？」

辅助透镜：
- 防御机制：遵循 [SKILL.md 的解释边界](../SKILL.md#防御机制与重复强迫解释候选不是行为标签)，呈现方式见下方虚构示例。
- 重复模式：这些话只提供意愿线索，不能证明小林反复采取了什么行为。需要了解不同事件中实际做了什么、在什么条件下不同，再按 [模式证据规则](memory-schema.md#模式的最小证据) 比较；没有找到反例就写“暂未找到，待核对”，不能写成“没有反例”或确认存在模式。
- 自由联想：虚构的小林若在选项式追问后回答“都不是”，可接：「你会怎样描述自己想要的？」开放问题仍难以展开时，遵循 [情境线索方法](../SKILL.md#自由联想情境线索)，呈现方式见下方虚构示例。

## 自我淡化线索（虚构示例）

先核对表达差异，不直接断定合理化、回避或否认：

- 留意限定词是否缩小了用户所述贡献，结合具体困难、做法与结果核对；客观范围限定、谦逊或表达习惯也是可能解释，单个词不能证明防御机制，也不预设某类工作价值低。
- 只有另有夸大他人能力、忽略其局限的原话线索时，才考虑“理想化他人”的可能解读；不能由自我淡化反推，也不把客观赞赏当成理想化。
- 保留限定词呈现原话，只问一个开放问题；不预设去掉限定词后一定更正面，不替用户重写贡献，不用吹捧纠正表达。用户不认同就撤回，不把纠正视为防御证据。

以下人物、原话和日期均为虚构。

事实素材（本人陈述）：小岑于 2026-02-03 说：“我排查了多次失败的原因，重新安排步骤后终于完成了道具搭建，但这就是个手工活。”事件日期未知；这里只能确认小岑这样描述过。

可能的解读（AI 假设，防御机制视角）：原话中的“就是个手工活”可能淡化了前面所述的排查与调整，也可能只是在说明工作类别，尚不能判断。原话证据：“我排查了多次失败的原因，重新安排步骤后终于完成了道具搭建，但这就是个手工活。”（本人陈述，2026-02-03；事件日期未知）。

只问一个问题：「如果去掉“就是个”，你会怎么描述它？」随后等待回应；这段原话没有评价他人，不引出“理想化他人”的解读。

## 能力缺口与呈现张力

- 用户同时描述能力缺口与夸大呈现的冲动时，可以探索希望呈现的自我与现实经验之间的张力；不能自动等同于超我要求，需核对其本人认可的标准、期待与现实压力。不做道德或人格评判，用户不认同就撤回。
- 每轮只选一个开放问题，先了解实际做到的部分与局限；只有用户想改进时才讨论计划。明确区分已经做到、仍需帮助和准备学习，不把计划写成已有能力或已完成成果。
- 可以帮助准确表达已有能力与贡献；不协助编造经历、成果、职责或技术细节，也不把不熟悉改写成精通。

**完全虚构的示例**：某虚构用户说：“我只跟着教程做过一个陶杯，烧制细节还不懂，但想写成‘熟练掌握陶艺’。”可回应：“你希望呈现的熟练程度和目前的经验之间可能有些拉扯，这只是一个可纠正的理解。你会怎么描述自己目前实际能做到的部分？”等待回答，不替其补造经验，也不预设其已经决定学习。

## 情境线索（虚构示例）

以下人物与场景均为虚构。小陶已说自己负责剧场服装，面对开放问题仍说“不知道从哪讲”，但愿意继续聊。可给出：

- 【用于挖素材，不代表你做过】临近排练，服装还需调整，排练时间已经定下。
- 【用于挖素材，不代表你做过】旧戏服可以修补，新做一套也有各自的成本和限制。
- 【用于挖素材，不代表你做过】一次演出结束后，还有几件服装等待处理。

只作一次邀请：「这些场景不预设你的经历；挑一条有感觉的随意说，想到别的也可以，都不贴合或不想继续也没关系。」随后等待，不逐条追问；具体保存与主题归纳沿用上述方法。
